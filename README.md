# Dakingo - Online Cake & Bakery Landing Page

Una réplica funcional de alta fidelidad para la tienda online de pastelería gourmet **Dakingo**, diseñada para ofrecer una experiencia visual rica y deliciosa en todos los dispositivos.

## 🍰 Características Principales

- **Diseño de Alta Fidelidad**: Paleta de colores carmesí/vino tinto (`#8D1D24`), fondos cálidos crema y tarjetas suaves.
- **Hero Banner Interactivo**: Muestra el pastel de chocolate artesanal, pasteles de lava derretida y brownie en marcos circulares, con insignia de descuento interactiva (20% OFF con código `BLISS20`).
- **Menú y Filtros Dinámicos**: Categorías de navegación (*Classic, Gourmet, Desserts, Cookies*) con filtro en tiempo real.
- **Bestsellers con E-commerce Funcional**:
  - Catálogo de pasteles más vendidos con precios, descuentos y reseñas.
  - Carrito de compras deslizante (*Drawer*) con control de cantidades, cálculo de subtotales y total con descuentos.
  - Lista de deseos (*Wishlist*) interactiva con corazones animados.
  - Vista rápida de producto con selector de peso (0.5 Kg, 1.0 Kg, 2.0 Kg), preferencia dietética (100% vegetariano/eggless) y precio dinámico.
- **Sección Our Promise**:
  - Sellos de garantía de entrega rápida, diseños exclusivos y frescura garantizada.
  - Modal interactivo **The Magical Ticket** para registrar recordatorios de cumpleaños/aniversarios y desbloquear cupones de descuento.
  - Cuadrícula de fotos 2x3 de la pastelería y chefs.
- **Formulario de Pedido (Checkout)**: Selector de fecha de entrega, franja horaria (Estándar o Medianoche), mensaje en el pastel, dirección de entrega y métodos de pago.
- **Buscador en Tiempo Real**: Búsqueda instantánea de pasteles por nombre.
- **Asistente de Soporte Virtual**: Botón flotante para resolver dudas frecuentes sobre envíos e ingredientes.

## 🚀 Cómo Ejecutar Localmente

No requiere instalación de dependencias complejas. Puedes abrir el proyecto de cualquiera de estas dos formas:

### Opción 1: Directo en el Navegador
Haz doble clic sobre el archivo `index.html`.

### Opción 2: Con Servidor Local
```bash
python -m http.server 3000
```
Luego abre tu navegador en `http://localhost:3000`.

## 🛠️ Tecnologías

- **HTML5 Semántico**: Estructura accesible y optimizada para SEO.
- **CSS3 Puro**: Sin librerías externas para máximo rendimiento y control visual.
- **JavaScript Moderno (ES6+)**: Lógica reactiva modular sin dependencias.
- **Google Fonts**: *Poppins*, *Playfair Display* y *Caveat*.
